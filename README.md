# hypergraph forum

A forum for a group of friends, with no server and no company in the middle. Each member runs it on
their own computer; posts go straight from computer to computer. Invite-only.

**Not built yet.** The plan is in [`specs/001-forum/`](specs/001-forum/).

## Install (once it exists)

You need [Node.js](https://nodejs.org) 20 or newer and git. Then copy-paste one line:

- Windows (PowerShell): `irm <install.ps1 URL> | iex`
- macOS / Linux: `curl -fsSL <install.sh URL> | sh`

It opens the forum in your browser. Paste the invite code a friend sent you, or the device code from
your other computer.
